## 流程說明

### Path A — 每日自動推播

```
Cloud Scheduler (每日 08:30 CST)
  → animeDailyPush [GCP Cloud Function]
  → AniList GraphQL: fetchTodayAiring()
  → Wikipedia JA/ZH: enrich() x3 concurrent
  → Neon PostgreSQL: saveAnimes / loadAnimes
  → validateData() [聲優全空? Yes→推送警告/中止]
  → buildFlexMessage() [Carousel x12]
  → LINE Push API: pushMessage()
  → LINE User
```

### Path B — 動漫簡介 Webhook

```
LINE User 點擊「動漫簡介」按鈕
  → LINE Platform [Postback Event]
  → animeDailyPush [GCP Cloud Function, Webhook route]
  → verifyLineSignature() [HMAC-SHA256]
  → AniList GraphQL: fetchNativeTitleById()
  → Wikipedia JA: fetchJapaneseSynopsis()
  → LINE Reply API: replyMessage()
  → LINE User 收到簡介
```
